# Changelog

## 0.1.0 — Initial public release

- Native Windows 11 widget built with Tauri 2, Svelte 5, TypeScript, and Rust.
- Local fixed-precision transaction ledger with FIFO cost basis.
- Optional Cash and Margin Debt accounting with per-trade funding control.
- Reconstructed daily and hourly portfolio history.
- Regular and extended-hours quote modes.
- Responsive layout, adjustable typography, privacy masking, and chart ranges.
- Local persistence, window-state restoration, autostart, and taskbar controls.
